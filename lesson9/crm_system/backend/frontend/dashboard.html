Contact Search & Real-time Metrics — Lesson: Filtering by Name

Progressive Search Architecture

GET /contacts?name=... uses a LIKE clause in SQL for filtering. This is the minimum viable approach: fine for small datasets. At scale, a leading wildcard %name% prevents index use (full table scan). Future upgrade path: full-text search (e.g. Elasticsearch) for large data.

Data flow: Client → Backend (extract name) → Repository (SQL LIKE) → PostgreSQL → JSON response → Client
