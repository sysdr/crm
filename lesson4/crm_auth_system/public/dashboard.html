📋 About This Project

CRM Auth System is a secure authentication microservice built with Node.js, Express, and PostgreSQL. It provides enterprise-grade user authentication with JWT (JSON Web Tokens) for stateless session management.

Main Goals: Demonstrate secure user registration, password hashing with bcrypt, JWT-based authentication, and protected route access - core building blocks for any modern CRM or SaaS application.

🔒 Bcrypt Password Hashing
🎫 JWT Token Authentication
🐘 PostgreSQL Database
🐳 Docker Containerized
🛡️ Protected Routes
⚡ RESTful API Design
